# Portafolio Profesional - Susej Gonzalez

Este es mi portafolio personal interactivo, diseñado para mostrar mi trayectoria como Desarrolladora Web Junior. El sitio está enfocado en la experiencia de usuario (UX), el rendimiento y la integración de herramientas modernas de desarrollo, incluyendo asistencia por Inteligencia Artificial.

**🌐 Demo en vivo:** [https://susejgo89.github.io/portafolio-personal/](https://susejgo89.github.io/portafolio-personal/)

---

## 🚀 Características Principales

- **Sistema Multilingüe:** Soporte completo para Español, Inglés y Portugués con persistencia de preferencia mediante `localStorage`.
- **Asistente Virtual IA:** Chatbot interactivo integrado que responde preguntas sobre mi perfil, formación y proyectos basado en datos de mi currículum.
- **Diseño Premium & Minimalista:** Interfaz limpia con tipografía cuidada, efectos magnéticos, cursor trail y animaciones de scroll.
- **Proyectos Interactivos:** Secciones detalladas mediante acordeones que explican el problema, el rol y el desafío técnico de cada desarrollo.
- **Galería Multimedia:** Sliders de imágenes con funcionalidad de Lightbox para una visualización detallada de los proyectos.
- **Totalmente Responsivo:** Adaptado para una experiencia fluida en dispositivos móviles, tablets y escritorio.

## 🛠️ Tecnologías Utilizadas

### Frontend
- **HTML5 & CSS3:** Estructura semántica y estilos personalizados.
- **Tailwind CSS:** Framework de utilidades para un diseño rápido y moderno.
- **JavaScript (ES6+):** Lógica personalizada para traducciones, sliders y chatbot sin dependencias pesadas.
- **Lucide Icons:** Set de iconos consistentes y ligeros.

### Herramientas y Metodologías
- **IA-Enhanced Development:** Uso proactivo de Inteligencia Artificial para la optimización de código y resolución de problemas.
- **Mobile First:** Estrategia de diseño centrada en el usuario móvil.
- **Google Fonts:** Integración de fuentes optimizadas para la web.

## 📂 Estructura del Proyecto

```bash
portafolio/
├── css/
│   └── style.css          # Estilos personalizados y animaciones
├── js/

├── images/               # Activos visuales y capturas de proyectos

```
